챔피언스시티 업로드 (공유 저장 · 다른 컴퓨터에 상담카드가 안 보이던 문제 수정)

[원인]
서버에 이미 다른 기기(빈 휴대폰 등)의 자료가 먼저 올라가 있으면,
상담카드가 있던 컴퓨터가 접속할 때 서버 자료로 '덮어쓰기'만 하고 자기 상담카드는 올리지 않았습니다.
그래서 다른 컴퓨터에서는 빈 상태로 보였습니다.

[수정]
- 접속할 때 서버 자료와 이 기기 자료를 '합칩니다'. 서버에 없는 상담카드 · 호실 상태 · 매수대기는 자동으로 서버에 올라갑니다.
- 그 기기에서 처음 공유를 켤 때는 직원 · PIN · 연락처 목록도 서버 목록과 합칩니다 (빠진 직원 복구).
- 아무 자료가 없는 새 기기는 기본값을 서버에 올리지 않습니다 (다른 기기 설정을 덮어쓰지 않음).
- 한 번 공유된 뒤에 삭제한 직원은 다시 살아나지 않습니다.

[올리는 파일]
public/dashboard.dc.html   (덮어쓰기 · wrangler.jsonc · src/worker.js 그대로)

[방법]
1) public/dashboard.dc.html 덮어쓰기 → Summary '공유 합치기 수정' → Commit to main → Push origin
2) Deployments 성공 확인 (2~3분)

[올린 뒤 순서]
1) 상담카드 · 매수대기를 입력했던 컴퓨터에서 /staff/ 접속 → Ctrl+F5 → 로그인
   → 상단 '저장 중… N건' 이 잠깐 보였다가 '● 공유 저장됨' 으로 바뀌면 서버에 올라간 것
   (안 바뀌면: 설정 맨 아래 [이 기기 자료를 서버로 올리기] 를 한 번 누르기)
2) 다른 컴퓨터 · 휴대폰에서 Ctrl+F5 (휴대폰은 새로고침) → 로그인 → 같은 상담카드가 보이면 성공
   (안 보이면 로그인 창 아래 [서버에서 다시 받기])

[주의]
- 1번은 자료가 들어 있는 컴퓨터에서 해야 합니다. 그 컴퓨터에서 인터넷 사용기록을 지웠다면 그 기기 자료는 이미 없어진 상태입니다.
  이 경우 구글시트 '① 상담_챔스' 에 남은 기록을 보고 다시 입력해야 합니다.
